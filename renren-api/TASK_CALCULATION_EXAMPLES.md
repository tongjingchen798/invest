# 任务计算逻辑示例

## 任务计算规则说明

**重要说明：所有任务都根据用户总推荐人数来判断，而不是根据投资、充值、收益等数据**

### 任务1：推荐人数任务（最大1）
显示推荐人数，但最大不超过1

### 任务2：推荐人数额外任务（最大2）
显示剩余推荐人数（推荐人数 - 任务1显示数量），但最大不超过2

### 任务3：投资金额任务（最大2）
显示剩余推荐人数（推荐人数 - 任务1显示数量 - 任务2显示数量），但最大不超过2

### 任务4：充值任务（最大2）
显示剩余推荐人数（推荐人数 - 任务1显示数量 - 任务2显示数量 - 任务3显示数量），但最大不超过2

### 任务5：收益任务（最大5）
显示剩余推荐人数（推荐人数 - 任务1显示数量 - 任务2显示数量 - 任务3显示数量 - 任务4显示数量），但最大不超过5

## 具体用户示例

### 示例1：推荐4个用户
```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "completeNum1": 1,    // 推荐4个用户，任务1显示1，剩余3
    "completeNum2": 2,    // 剩余3分配给任务2，任务2显示2，剩余1
    "completeNum3": 1,    // 剩余1分配给任务3，任务3显示1
    "completeNum4": 0,    // 剩余0，任务4显示0
    "completeNum5": 0     // 剩余0，任务5显示0
  }
}
```

## 注意事项

1. **任务2的特殊性**：只有推荐人数达到3个以上时才会显示数量
2. **等级计算**：投资、充值、收益任务都采用整数除法计算等级
3. **边界条件**：所有任务在未达到条件时都显示0
4. **最大值限制**：每个任务都有最大完成数量限制，超过限制时显示最大值
5. **扩展性**：任务计算逻辑可以根据业务需求灵活调整
