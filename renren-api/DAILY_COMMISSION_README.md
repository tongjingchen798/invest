# 每日佣金统计功能说明文档

## 概述

本文档详细说明了系统每日佣金统计功能的实现，包括佣金计算规则、执行时间、配置参数等。

## 功能说明

### 1. 佣金计算规则

| 级别 | 推荐关系 | 佣金比例 | 说明 |
|------|----------|----------|------|
| 1级 | 直属推荐 | 7% | 直接推荐人获得投资金额的7%佣金 |
| 2级 | 间接推荐 | 3% | 间接推荐人获得投资金额的3%佣金 |

### 2. 计算逻辑

1. **统计范围**：统计昨日（00:00:00 - 23:59:59）的所有投资记录
2. **用户分组**：按投资用户ID分组，汇总每个用户的投资总金额
3. **佣金计算**：根据推荐关系计算1级和2级推荐人的佣金
4. **字段更新**：更新推荐人用户表中的相关佣金字段

### 3. 佣金字段更新

更新以下字段：
- `commission_balance`：佣金余额（累加）
- `history_commission_balance`：历史累计佣金（累加）
- `today_commission`：今日佣金（累加）

## 配置参数

### 1. 佣金比例配置

```yaml
commission:
  # 1级直属推荐佣金比例（百分比）
  first-level-rate: 7
  # 2级推荐佣金比例（百分比）
  second-level-rate: 3
  # 是否启用佣金计算
  enabled: true
  # 佣金计算时间（每天凌晨几点执行）
  cron-expression: "0 0 2 * * ?"
```

### 2. 配置说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `first-level-rate` | 7 | 1级推荐佣金比例，单位：百分比 |
| `second-level-rate` | 3 | 2级推荐佣金比例，单位：百分比 |
| `enabled` | true | 是否启用佣金计算功能 |
| `cron-expression` | "0 0 2 * * ?" | 定时任务执行时间，默认每天凌晨2点 |

## 执行流程

### 1. 任务触发

- **执行时间**：每天凌晨2点（可配置）
- **执行方式**：Spring Boot定时任务（@Scheduled）
- **事务管理**：使用@Transactional确保数据一致性

### 2. 执行步骤

1. **配置检查**：检查佣金计算功能是否启用
2. **日期计算**：获取昨日日期范围
3. **数据查询**：查询昨日所有投资记录
4. **用户分组**：按投资用户ID分组统计投资金额
5. **佣金计算**：遍历每个投资用户，计算推荐人佣金
6. **数据更新**：更新推荐人用户表的佣金字段
7. **日志记录**：记录执行过程和结果

### 3. 佣金计算示例

假设用户A投资1000卢比（100000分），推荐关系如下：

```
用户C（2级推荐人）
    ↓
用户B（1级推荐人）
    ↓
用户A（投资用户）
```

**佣金计算**：
- 1级推荐人（用户B）：1000 × 7% = 70卢比
- 2级推荐人（用户C）：1000 × 3% = 30卢比

## 技术实现

### 1. 核心类

- **DailyCommissionSchedule**：定时任务主类
- **CommissionConfig**：佣金配置类
- **UserDao**：用户数据访问层

### 2. 关键方法

#### calculateDailyCommission()
- 主任务方法，每天执行一次
- 统计昨日投资记录并计算佣金

#### calculateCommissionForInvestor()
- 为单个投资用户计算推荐人佣金
- 支持1级和2级推荐关系

#### calculateCommission()
- 计算佣金金额
- 处理分与卢比的转换

#### updateUserCommission()
- 更新用户佣金相关字段
- 使用数据库事务确保数据一致性

### 3. 数据库操作

#### 查询操作
```sql
-- 根据日期范围查询投资记录
SELECT * FROM tb_investment_record 
WHERE create_time >= #{startDate} AND create_time < #{endDate}

-- 根据邀请码查询用户
SELECT * FROM tb_user WHERE invite_code = #{inviteCode}
```

#### 更新操作
```sql
-- 更新用户佣金字段
UPDATE tb_user SET 
    commission_balance = commission_balance + #{commissionAmount},
    history_commission_balance = history_commission_balance + #{commissionAmount},
    today_commission = today_commission + #{commissionAmount}
WHERE id = #{userId}
```

## 注意事项

### 1. 数据一致性

- 使用数据库事务确保佣金计算的原子性
- 投资金额按用户ID分组，避免重复计算
- 佣金字段累加更新，支持多次投资

### 2. 性能优化

- 按日期范围查询投资记录，减少数据扫描
- 使用Map进行用户投资金额分组统计
- 批量更新用户佣金字段

### 3. 异常处理

- 单个用户佣金计算失败不影响其他用户
- 详细的日志记录，便于问题排查
- 配置开关控制，可临时禁用功能

### 4. 时间处理

- 使用Calendar精确计算昨日时间范围
- 考虑时区问题，使用系统默认时区
- 时间范围：昨日00:00:00 - 23:59:59
