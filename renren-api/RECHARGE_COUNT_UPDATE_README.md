# 充值统计更新功能说明文档

## 概述

在充值成功后，系统会自动更新用户的充值统计信息，包括充值次数和充值金额的统计。

## 功能特性

- 充值成功后自动触发
- 更新今日充值次数和历史充值次数
- 更新今日充值金额和累计充值金额
- 事务安全，确保数据一致性
- 每日自动重置今日充值相关字段

## 数据库字段

| 字段名 | 说明 | 更新规则 |
|--------|------|----------|
| `today_recharge_cnt` | 今日充值次数 | 充值成功时+1，每日重置 |
| `historychargecnt` | 历史充值次数 | 充值成功时+1，永不重置 |
| `today_recharge` | 今日充值金额(分) | 充值成功时+充值金额，每日重置 |
| `charge_sum` | 累计充值金额(分) | 充值成功时+充值金额，永不重置 |

## 实现方式

在充值成功后，调用 `userDao.updateAllRechargeFields(userId, amount)` 方法综合更新充值次数和金额。

## 定时任务

系统每天0点自动重置用户的今日充值相关字段：
- `today_recharge`: 重置为0
- `today_recharge_cnt`: 重置为0
