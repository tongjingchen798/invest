# 提现规则说明文档

## 概述

本文档详细说明了系统提现功能的各项规则和限制，包括提现金额限制、手续费计算、次数限制等。

## 提现规则配置

### 1. 金额限制

| 规则项 | 数值 | 说明 |
|--------|------|------|
| 单笔最低提现额度 | 200 RS | 每次提现不能少于200卢比 |
| 单笔最高提现额度 | 100,000 RS | 每次提现不能超过10万卢比 |

### 2. 手续费规则

| 规则项 | 数值 | 说明 |
|--------|------|------|
| 手续费率 | 5% | 按提现金额的5%收取手续费 |
| 计算方式 | 按比例 | 手续费 = 提现金额 × 5% |
| 实际到账 | 95% | 实际到账金额 = 提现金额 - 手续费 |

### 3. 其他设置

| 规则项 | 数值 | 说明 |
|--------|------|------|
| 提现验证码 | 启用 | 提现时需要输入验证码 |
| 审核时间 | 24小时 | 提现申请审核时间不超过24小时 |

## 手续费计算示例

### 示例1：提现1000 RS
- 提现金额：1000 RS
- 手续费：1000 × 5% = 50 RS
- 实际到账：1000 - 50 = 950 RS

### 示例2：提现5000 RS
- 提现金额：5000 RS
- 手续费：5000 × 5% = 250 RS
- 实际到账：5000 - 250 = 4750 RS

### 示例3：提现10000 RS
- 提现金额：10000 RS
- 手续费：10000 × 5% = 500 RS
- 实际到账：10000 - 500 = 9500 RS

## API接口说明

### 1. 获取提现规则

**接口地址：** `GET /api/withdraw/rules`

**功能说明：** 获取系统当前的提现规则配置

**返回示例：**
```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "minAmount": 200,
    "maxAmount": 100000,
    "feeRate": 5,
    "percentageFee": true,
    "fixedFee": 0,
         "enableVerificationCode": true,
    "auditTime": 24,
    "description": "提现规则说明",
    "feeDescription": "手续费按提现金额的5%收取"
  }
}
```

### 2. 计算提现费用

**接口地址：** `GET /api/withdraw/calculate?amount={amount}`

**功能说明：** 根据提现金额计算手续费和实际到账金额

**参数说明：**
- `amount`: 提现金额（卢比）

**返回示例：**
```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "withdrawAmount": 1000,
    "fee": 50,
    "realAmount": 950,
    "feeRate": "5%",
    "feeDescription": "手续费按提现金额的5%收取"
  }
}
```

### 3. 验证提现金额

**接口地址：** `GET /api/withdraw/validate?amount={amount}`

**功能说明：** 验证提现金额是否符合规则

**参数说明：**
- `amount`: 提现金额（卢比）

**返回示例：**
```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "valid": true,
    "message": null,
    "amount": 1000,
    "minAmount": 200,
    "maxAmount": 100000,
    "fee": 50,
    "realAmount": 950
  }
}
```

## 配置文件

提现规则配置位于 `application.yml` 文件中：

```yaml
# 提现规则配置
withdraw:
  # 单笔最低提现额度（卢比）
  min-amount: 200
  # 单笔最高提现额度（卢比）
  max-amount: 100000
  # 提现手续费率（百分比）
  fee-rate: 5
  # 手续费计算方式：true为按比例，false为固定金额
  percentage-fee: true
  # 固定手续费金额（卢比），当percentage-fee为false时使用
  fixed-fee: 0
  # 是否启用提现验证码
  enable-verification-code: true
  # 提现审核时间（小时）
  audit-time: 24
```

## 业务逻辑

### 1. 提现申请流程

1. **金额验证**：检查提现金额是否在允许范围内（200-100000 RS）
2. **余额验证**：检查用户账户余额是否充足
3. **手续费计算**：按5%计算手续费
4. **创建订单**：生成提现订单记录
5. **余额扣减**：扣除用户账户余额
6. **状态更新**：设置订单状态为"待审核"

### 2. 规则验证逻辑

- **最低额度**：提现金额必须 ≥ 200 RS
- **最高额度**：提现金额必须 ≤ 100,000 RS
- **手续费**：统一按5%收取，四舍五入到2位小数

### 3. 异常处理

- **金额超限**：返回"提现金额超出允许范围"错误
- **余额不足**：返回"账户余额不足"错误
- **系统异常**：返回"系统异常，请稍后重试"错误

## 注意事项

1. **手续费计算**：手续费按提现金额的5%计算，四舍五入到2位小数
2. **状态流转**：提现订单状态：待审核 → 审核通过 → 处理中 → 已完成/失败
3. **审核时间**：提现申请审核时间不超过24小时
4. **验证码**：提现时需要输入验证码，提高安全性
