# 付工资功能说明

## 功能概述
付工资功能允许管理员为指定用户发放工资，系统会自动更新用户余额并记录相关交易明细。

## 接口信息

### 接口地址
- **URL**: `PUT /user/fgz`
- **方法**: PUT
- **权限**: 需要管理员权限

### 请求参数
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | Long | 是 | 用户ID |
| balance | Long | 是 | 工资金额（单位：分） |

### 请求示例
```bash
PUT /user/fgz?id=1958922146164248577&balance=10000
```

### 响应格式
```json
{
  "code": 0,
  "msg": "工资发放成功",
  "data": "工资发放成功"
}
```

## 功能特性

### 1. 参数验证
- 用户ID必须存在且大于0
- 工资金额必须大于0
- 用户必须存在于系统中

### 2. 余额更新
- 自动更新用户的可用余额（assets字段）
- 支持累加工资到现有余额

### 3. 交易记录
- 自动记录到余额明细表（user_balance_detail）
- 业务类型标记为12（工资）
- 记录发放渠道、时间、金额等详细信息

### 4. 事务安全
- 使用Spring事务管理
- 余额更新和明细记录在同一事务中
- 失败时自动回滚

## 数据库影响

### 更新表
- `tb_user`: 更新用户余额
- `user_balance_detail`: 插入工资发放记录

### 字段说明
- `assets`: 用户可用余额（分）
- `business_type`: 业务类型（12=工资）
- `original_amount`: 工资金额（分）
- `remarks`: 备注（工资发放）

## 使用场景

1. **员工工资发放**: 为员工发放月度工资
2. **奖励发放**: 发放绩效奖金或特殊奖励
3. **补偿发放**: 发放各种补偿款项

## 注意事项

1. **金额单位**: 所有金额都以分为单位，避免浮点数精度问题
2. **权限控制**: 需要管理员权限才能执行工资发放
3. **日志记录**: 所有操作都会记录详细日志，便于审计
4. **数据一致性**: 使用事务确保余额和明细数据的一致性

## 错误处理

| 错误情况 | 错误信息 | 处理方式 |
|----------|----------|----------|
| 用户ID为空 | 用户ID不能为空 | 检查参数 |
| 金额无效 | 工资金额必须大于0 | 检查金额参数 |
| 用户不存在 | 用户不存在 | 检查用户ID |
| 系统异常 | 工资发放失败 | 查看日志，联系技术支持 |

## 测试方法

1. 使用提供的测试脚本 `test-salary.bat`
2. 修改脚本中的用户ID和金额参数
3. 确保系统正常运行
4. 执行脚本测试接口功能
