# 用户标签修改功能说明

## 功能概述
用户标签修改功能允许管理员为指定用户设置或清除标签，用于用户分类和管理。

## 接口信息

### 接口地址
- **URL**: `PUT /user/updateUserBq`
- **方法**: PUT
- **权限**: 需要管理员权限

### 请求参数
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | Long | 是 | 用户ID |
| biaoqian | Integer | 是 | 标签值 |
| type | Integer | 是 | 操作类型：1-设置标签，2-清除标签 |

### 请求示例

#### 设置标签
```bash
PUT /user/updateUserBq?id=1958922146164248577&biaoqian=1&type=1
```

#### 清除标签
```bash
PUT /user/updateUserBq?id=1958922146164248577&biaoqian=1&type=2
```

### 响应格式
```json
{
  "code": 0,
  "msg": "标签修改成功",
  "data": "标签修改成功"
}
```

## 功能特性

### 1. 参数验证
- 用户ID必须存在且大于0
- 标签值不能为空
- 操作类型必须为1(设置标签)或2(清除标签)
- 用户必须存在于系统中

### 2. 标签操作
- **设置标签**: 将指定标签值设置到用户记录中
- **清除标签**: 将用户标签设置为null

### 3. 数据安全
- 使用Spring事务管理
- 失败时自动回滚
- 完整的日志记录

### 4. 操作记录
- 记录标签修改的详细信息
- 包含用户ID、标签值、操作类型等

## 数据库影响

### 更新表
- `tb_user`: 更新用户的biaoqian字段

### 字段说明
- `biaoqian`: 用户标签字段，存储标签值或null

## 使用场景

1. **用户分类**: 为不同用户设置不同的标签进行分类
2. **权限管理**: 根据标签控制用户权限
3. **营销策略**: 根据标签进行精准营销
4. **数据分析**: 基于标签进行用户行为分析

## 操作类型说明

| 类型值 | 操作 | 说明 |
|--------|------|------|
| 1 | 设置标签 | 将指定标签值设置到用户记录中 |
| 2 | 清除标签 | 将用户标签设置为null |

## 注意事项

1. **标签值**: 标签值可以是任意整数，建议使用有意义的数值
2. **权限控制**: 需要管理员权限才能执行标签修改
3. **日志记录**: 所有操作都会记录详细日志，便于审计
4. **数据一致性**: 使用事务确保数据的一致性

## 错误处理

| 错误情况 | 错误信息 | 处理方式 |
|----------|----------|----------|
| 用户ID为空 | 用户ID不能为空 | 检查参数 |
| 标签值为空 | 标签值不能为空 | 检查标签参数 |
| 操作类型无效 | 操作类型必须为1(设置标签)或2(清除标签) | 检查操作类型参数 |
| 用户不存在 | 用户不存在 | 检查用户ID |
| 系统异常 | 标签修改失败 | 查看日志，联系技术支持 |

## 测试方法

1. 使用提供的测试脚本 `test-update-biaoqian.bat`
2. 修改脚本中的用户ID、标签值和操作类型参数
3. 确保系统正常运行
4. 执行脚本测试接口功能

## 标签筛选功能

在会员查询接口中，标签筛选支持以下功能：
- 按具体标签值筛选
- 按是否有标签筛选（有标签=1，无标签=0）
- 支持模糊查询和精确匹配
