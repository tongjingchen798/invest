# 即将兑付金额查询功能说明

## 功能概述
即将兑付金额查询功能提供对用户即将兑付金额的查询，支持按代理、业务员、时间范围等条件筛选，并支持分页查询和排序。

## 接口信息

### 基本信息
- **接口地址**: `GET /admin/user/amounttobecashed`
- **请求方式**: `GET`
- **请求类型**: `application/x-www-form-urlencoded`
- **响应类型**: `application/json`

### 请求参数

| 参数名称 | 参数说明 | 是否必须 | 数据类型 | 示例值 |
|----------|----------|----------|----------|--------|
| page | 当前页码，从1开始 | 是 | int | 1 |
| limit | 每页显示记录数 | 是 | int | 10 |
| agent | 代理下拉框 | 否 | long | 1 |
| salesmanid | 业务员下拉框 | 否 | long | 1 |
| startTime | 开始日期时间戳 | 否 | long | 1640995200000 |
| endTime | 结束日期时间戳 | 否 | long | 1640995200000 |
| order | 排序方式，可选值(asc、desc) | 否 | string | "desc" |
| orderField | 排序字段 | 否 | string | "create_date" |

### 响应数据结构

#### 即将兑付金额信息 (AmountToBeCashedDTO)
| 字段名 | 说明 | 类型 |
|--------|------|------|
| profitAmount | 兑付金额 | integer |
| profitDate | 兑付日期 | string |

## 功能特性

### 1. 多维度筛选
- **代理筛选**: 按代理ID筛选用户
- **业务员筛选**: 按业务员ID筛选用户
- **时间筛选**: 按创建时间范围筛选

### 2. 灵活排序
- **排序方式**: 支持升序(asc)和降序(desc)
- **排序字段**: 可自定义排序字段，默认按创建时间排序

### 3. 分页查询
- **分页支持**: 支持分页查询，每页记录数限制在1-1000之间
- **数据统计**: 返回总记录数和分页数据

## 使用场景

### 1. 兑付管理
- 查看用户的即将兑付金额
- 按时间范围统计兑付情况
- 按代理或业务员分组查看

### 2. 财务分析
- 分析兑付金额分布
- 统计兑付时间趋势
- 评估兑付风险

### 3. 业务监控
- 监控兑付进度
- 分析兑付模式
- 提供决策支持

## 注意事项

1. **分页限制**: 每页记录数限制在1-1000之间
2. **时间格式**: 时间参数使用时间戳格式（毫秒）
3. **排序字段**: 如果不指定排序字段，默认按创建时间排序
4. **权限控制**: 需要相应的权限才能访问

## 业务逻辑说明

当前实现中，兑付金额使用 `historyProfit`（历史收益）字段作为示例，兑付日期使用 `createDate`（创建日期）作为示例。在实际业务中，您可能需要：

1. 根据具体的兑付业务逻辑调整字段映射
2. 添加兑付状态、兑付类型等字段
3. 实现更复杂的兑付计算逻辑
4. 添加兑付确认、兑付记录等功能
